# Bonnenboek

Installeerbare app (PWA) om samen de boodschappenuitgaven bij te houden door kassabonnen te scannen.

- `public/` — de app (index.html, app.js, service worker, manifest, iconen)
- `netlify/functions/` — gedeelde opslag per huishouden (Netlify Blobs) en het uitlezen van bonnen (Claude via Netlify AI Gateway)

Netlify-project: **bonnenboek** → https://bonnenboek.netlify.app
